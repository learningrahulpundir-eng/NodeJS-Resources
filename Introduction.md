# Introduction to Node.js

Node.js is a JavaScript runtime environment that lets you run JavaScript outside of a browser, mainly on the server.

It is commonly used to build:
- APIs
- Web servers
- Real-time applications
- Command-line tools

## Why use Node.js?

### 1. Fast performance ⚡
- Powered by Chrome's V8 engine
- Executes code very quickly

### 2. One language for everything
- Use JavaScript for both frontend and backend
- Avoid learning multiple languages for different layers

### 3. Asynchronous and non-blocking
- Handles many requests at the same time
- Great for:
  - Chat applications
  - Real-time apps
  - APIs

> Example: Node.js does not wait for one task to finish before starting another.

### 4. Great for APIs and web apps
- Commonly used to build:
  - REST APIs
  - Microservices
  - Backend systems

### 5. Huge ecosystem with npm
- Comes with npm (Node Package Manager)
- Provides millions of ready-to-use libraries

### 6. Scalable
- Suitable for high-traffic applications
- Widely used in large-scale systems

## Where Node.js is used
- Netflix
- PayPal
- LinkedIn
- Uber

## When Node.js may not be the best choice
- Heavy CPU-bound tasks such as video processing
- Complex calculations that are better handled by other languages
